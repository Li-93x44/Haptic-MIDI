# Haptic-MIDI
A Haptic MIDI board to help beginners use MIDIs more easily
# NO CUSTOM PCB REQUIRED EVEN THOUGH PCB SCHEMATICS MIGHT BE VISIBLE IN REPO!!
This can be considered as Project for the Fallen series. The reason as to why I chose to do this as a project instead of something else is when i was choosing what I would do as my main project in fallen I had 2 options 1 of which was the mouse I chose to build the other was this MIDI so I started working on the mouse and I started working on this while the mouse project design has been sent to review.

# Purpose of this Project
Alongside my passion in projects like this and media I also have a passion in music more specifically EDM and Techno; a MIDI is one of the most frequently used items in this field during both the process of creating music and also while doing live performances and since it is one my many passions I thought I would make this during my past time.

# Benefits of me making this
Building the mouse doesn't take a lot of time or skill but it is still a hard project but building this requires a certain level of CAD, Schematics, and script knowledge way more than the mouse and this will hopefully help me improve my skills in this field and maybe in the music field as well.
